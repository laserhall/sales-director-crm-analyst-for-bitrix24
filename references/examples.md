# Examples

This directory contains synthetic examples only.

## Files

- `examples/anonymized-deal.json` — safe sample deal summary input.
- `examples/anonymized-openline-dialog.json` — safe sample Open Lines metadata and paraphrased dialog events.
- `examples/sample-report-single-deal.md` — example single-deal management report.
- `examples/sample-report-manager-review.md` — example manager review report.

## Anonymization rules used

- no real names;
- no phone numbers;
- no email addresses;
- no real webhook URLs;
- no full client messages;
- generic products/services;
- synthetic IDs.
