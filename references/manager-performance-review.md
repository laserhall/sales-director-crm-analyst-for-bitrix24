# Manager performance review

Use this reference to review a sales manager or team in Bitrix24.

## Inputs

- period;
- manager ID or team filter;
- pipeline/category;
- deal stage dictionary;
- source dictionary;
- deal list and activity metadata;
- selected Open Lines samples if communication quality is requested.

## Metrics

Quantitative:

- deals created;
- open deals;
- won deals;
- lost deals;
- conversion by stage;
- average stage age;
- deals without next activity;
- stale deals;
- first response SLA breaches;
- proposal follow-up breaches;
- CRM fields missing.

Qualitative:

- discovery quality;
- qualification discipline;
- commercial clarity;
- objection handling;
- next-step discipline;
- CRM notes and activity quality.

## Manager review output

```text
Manager:
Period:
Overall result:
Strengths:
Problems:
Deals to control:
Recommendations:
```

## Coaching approach

Focus on behavior and evidence:

- not `bad communication`, but `12 deals have no planned next step after proposal`;
- not `weak qualification`, but `budget/timing/decision-maker are absent in sampled dialogs`;
- not `CRM messy`, but `stage does not match last activity in these deal IDs`.

## Fairness rules

- Separate system/data access gaps from manager behavior.
- Compare similar sources and pipelines when possible.
- Do not expose private client details in manager summaries unless the report is explicitly internal.
- Use IDs for deal control lists.
